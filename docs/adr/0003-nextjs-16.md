# 0003. Next.js 16

Date: 2026-09-19
Status: Accepted

## Context

Spec section 3.2 names Next.js 15. Next.js 16.3 is the current stable at build time with React 19 and the same App Router model. Dom confirmed on 2026-09-19.

## Decision

`apps/web` uses Next.js 16.

## Consequences

Longer support runway. Any 15-specific guidance in the spec (none identified) is read against the 16 docs. shadcn and Auth.js versions are chosen for 16 compatibility.
